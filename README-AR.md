# مشروع تطبيق أندرويد APK - خدمات العمارة 🏢📱

تم إنشاء حزمة مشروع أندرويد ستوديو هذه بالكامل لتطبيق **"خدمات العمارة"**، وتحتوي على ملفات الكود المصدري وواجهة التطبيق المدمجة في مجلد Assets لتعمل بدون إنترنت (Offline 100%).

---

## 🚀 كيفية بناء ملف APK وتثبيته على هاتفك

لديك 3 طرق سهلة وسريعة للحصول على ملف `.apk`:

### 🌟 الطريقة 1: الفتح في أندرويد ستوديو (Android Studio) - الأسهل
1. قم بفك ضغط ملف الـ ZIP هذا على جهازك الكمبيوتر.
2. افتح برنامج **Android Studio**.
3. اختر **Open** ثم حدد المجلد الرئيسي للمشروع (المجلد الذي يحتوي على `settings.gradle`).
4. انتظر لحظات حتى يكتمل فحص الـ Gradle.
5. من القائمة العلوية اضغط على:
   **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
6. بعد انتهاء البناء (ثوانٍ معدودة)، سيظهر إشعار أسفل الشاشة به زر **locate**.
7. اضغط على **locate** لتجد ملف:
   `app/build/outputs/apk/debug/app-debug.apk`
8. أرسل هذا الملف لهاتفك (عبر واتساب أو البلوتوث أو كابل USB) وثبته فوراً!

---

### ☁️ الطريقة 2: البناء السحابي المجاني عبر GitHub Actions (بدون تثبيت أي برامج!)
إذا لم يكن لديك Android Studio أو كان جهازك بطيئاً:
1. ارفع محتويات هذا المجلد إلى مستودع جديد على **GitHub**.
2. ملف البناء جاهز بالفعل داخل المشروع في المسار:
   `.github/workflows/build-apk.yml`
3. اذهب إلى تبويب **Actions** في صفحة مستودع GitHub.
4. ستجد العملية تعمل تلقائياً، وبعد حوالي 2 إلى 3 دقائق ستجد ملف `app-debug.apk` جاهزاً للتحميل في قسم **Artifacts**!

---

### 💻 الطريقة 3: سطر الأوامر (Command Line)
إذا كان لديك أداة Gradle مثبتة، يمكنك تشغيل الأمر مباشرة:
```bash
# في أنظمة Linux / macOS:
./gradlew assembleDebug

# في أنظمة Windows:
gradlew.bat assembleDebug
```
وستجد الملف الناتج في:
`app/build/outputs/apk/debug/app-debug.apk`
